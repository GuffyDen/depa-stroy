# ДеПа Строй

Премиальный одностраничный сайт компании по комплексному ремонту квартир во Владивостоке.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка перед публикацией

```bash
npm run lint
npm run build
```

Рабочее название, юридическая подпись, контакты, показатели, проекты и временные отзывы
хранятся в `app/site-config.ts`.
